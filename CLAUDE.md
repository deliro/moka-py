# moka-py

Python bindings for the Rust [moka](https://github.com/moka-rs/moka) caching library, built with PyO3/maturin.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `deliro/moka-py`, driven via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary — each label string equals its canonical role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root, both created lazily. See `docs/agents/domain.md`.
